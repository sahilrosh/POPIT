# POPIT

POPIT is a Unity project repository.

## Requirements

- Unity Hub
- Unity Editor version compatible with this project (check `ProjectSettings/ProjectVersion.txt`)

## Getting Started

1. Clone this repository.
2. Open Unity Hub and click **Add** (or **Open**) to select this folder.
3. Let Unity import packages and compile scripts.
4. Open the main scene from the `Assets` folder and press **Play**.

## Project Structure

- `Assets/` - game assets, scenes, scripts, prefabs, and resources
- `Packages/` - package dependencies and manifest
- `ProjectSettings/` - Unity project configuration

## Version Control Notes

- This repository is configured with a Unity-focused `.gitignore`.
- Avoid committing generated folders like `Library/`, `Temp/`, and `Logs/`.
